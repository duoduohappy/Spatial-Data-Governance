# 评测设计（Stage 0 草案，**尚未执行任何评测**）

**状态声明：截至 Stage 0，尚未产生任何一个指标数字。** 本文件只定义方法与数据集规划。
任何对外材料中不得出现未经实测的提效比例、准确率或召回率。

## 1. 数据集规划

- 规模：20 个开发批次 + 10 个验证批次 + 20 个最终测试批次；记录量约 100 / 1,000 / 10,000 三档。
- 缺陷真值可定位到记录与字段；注入器、随机种子、标签与输入分开保存。
- 至少 80 条**人工标注的原子条款**，覆盖：可判定规则、模糊表述、不支持条款、相互冲突条款、无关内容。
  按文档模板拆分，不允许把同一模板改几个词当作独立测试。
- 至少一份来源许可明确的**真实公开数据**案例；真实存在的缺陷需人工确认；未发现真实缺陷如实记录。
- 最终集冻结并记录哈希；若曾用于调参则标记"已暴露"并另建最终集。
- 真值不进入模型上下文。

## 2. 对照实验

| 组 | 配置 | 目的 |
|---|---|---|
| A | 人工批准规则 + 确定性引擎 | 验证确定性执行本身 |
| B | 单 Agent 做条款提取/规则映射 + 同一引擎 + 同一审核政策 | 模型带来的增量 |
| C | 多 Agent + 同一引擎 + 同一审核政策 | **不预设 C 胜出**；没有收益就默认用 B |

B/C 使用相同输入、相同模型条件、相同预算上限，报告额外成本。全 LLM 判定不是首版必做。

## 3. 指标（10 项）

1. 条款提取 P / R / F1（对照人工原子条款，公开匹配判据）
2. 引用正确率（原文存在性自动查，语义支持人工查）
3. 规则映射正确率（类型 + 字段 + 关键参数 + 前置条件全对才算对）
4. 缺证据 / 不支持条款的识别率（保留且正确标未知的比例）
5. 错误放行率（不应通过却判 PASS 的比例；分别统计 FAIL→PASS 与 未知→PASS）
6. 缺陷定位 P / R（按规则 + 稳定记录定位，不通过重复计数扩大样本）
7. 人工总时间（含读说明、配置、复核、纠错，不单算生成速度）
8. 成本（含失败与重试；本地模型另报硬件与运行条件，不写零成本）
9. 延迟（模型与内核分开报；样本不足不报 p95）
10. 复验分类与人工真值的一致率

至少做一次人工工作流对照。争取两位 GIS 从业者试用；只有作者参与时必须标为"单人探索性测试"，
不外推普遍提效，且 AI 原始成绩与人工纠正后成绩分开报告。

## 4. 验收目标（是目标，不是成果）

- 规则、边界、聚合的预期用例全部通过；伪引用拦截率 100%。
- 最终挑战集零错误放行，同时报告样本量，不外推真实世界零风险。
- 条款提取 F1 ≥ 0.90、完整规则映射正确率 ≥ 0.90；未达标则降级为"逐条人工确认的实验版本"并在报告中写明。
- 规则变化不得被当成缺陷已解决；复验必测用例全对。
- 新环境按 README 可启动；无 Key 能跑内核，live AI 另行验证。
