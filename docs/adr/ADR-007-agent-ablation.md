# ADR-007 多 Agent 为实验组，以消融实验决定去留

- 状态：已采纳（原方案第 6 节的精神，本轮补充决策记录形式）
- 背景：多 Agent 容易被写成卖点，但如果没有对照数据，它就只是复杂度。
- 决策：单 Agent 是默认实现；多 Agent 只在实验组出现，并与单 Agent 在**相同输入、相同引擎、
  相同审核政策、相同预算上限**下对照。不预设多 Agent 胜出；没有收益就默认不用。
  无论结论如何，都要把对照结果做成一张公开的表并写出明确判断句。
- 理由：**诚实承认"更复杂的方案没被采用"比宣称多 Agent 更强更值钱**，这张表本身就是技术取舍的证据。
- 后果：Stage 4 必须产出对照表；若最后采用单 Agent，README 需写清理由与放弃的选项。
- 复审条件：Stage 4 出对照结果后立即依据数据改写本 ADR 的结论段。
