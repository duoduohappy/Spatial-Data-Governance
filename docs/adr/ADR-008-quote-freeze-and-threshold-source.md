# ADR-008 引用行号冻结 + 哈希校验 + 阈值必须有来源

- 状态：已采纳（Stage 0 已实施，并由 tools/selfcheck_guards.py 守护）
- 背景：条款—规则的映射一旦失去原文锚点，报告就变成无法验证的断言。
- 决策：
  1. 每个条款记录 document_sha256 + 冻结行号 + 逐字引用；引用内容与行内容不一致即失败；
  2. 规则的判定阈值必须能在原文引用中找到字面来源（max_age_days、max_distance_m、取值范围等）；
  3. 两者均由负面用例守护（伪造引用、无来源阈值必须被拦截）。
- 理由：这是"可追溯到原文"这条主张能不能站住的唯一技术保障。
- 后果：原文改了一个字就要重新批准规则；这会增加摩擦，但可以接受。
- 复审条件：Stage 2 模型开始自动提取条款时，必须保留同样的校验强度。
