# ADR-001 确定性内核与模型职责分离

- 状态：已采纳（Stage 0 已实施）
- 背景：空间数据的几何、范围、重复度量都可以用确定性算法判定；模型擅长的是从自然语言条款
  到结构化规则的转换与歧义解释。把两者混在一起，既不可复现也无法追责。
- 决策：**模型提议、人工批准、确定性工具判定。** 模型可以提 alias 映射、提阈值候选，
  但不得写入最终 verdict；execution 阶段不调用模型。
- 理由：可复现、可审计、成本低、失败语义清晰；也让"模型没跑通"不至于拖垮整条交付链路。
- 后果：需要维护一套规则表达（当前 YAML，Stage 1 起带 Schema）；人工批准成为必经环节。
- 复审条件：Stage 2 引入模型前复审，确认没有任何判定路径绕过内核。
