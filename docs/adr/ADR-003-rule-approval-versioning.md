# ADR-003 规则批准制 + 版本化 + 改参失效

- 状态：已采纳（Stage 0 已实施）
- 背景：规则是判定依据，一旦被静默修改，历史结论就失去可解释性。
- 决策：规则生命周期 DRAFT → NEEDS_CLARIFICATION / READY_FOR_REVIEW → APPROVED / REJECTED。
  缺必要参数或存在未解决歧义不得批准。批准后修改内容即产生新版本，旧批准自动失效。
- 理由：把"改了什么、谁批的、什么时候改的"变成可追溯的事实，而不是口头说法。
- 后果：需要在 manifest 中记录规则集合哈希；ui/报告需展示版本号。
- 复审条件：Stage 2 前复审（模型开始提议规则，批准流程会更频繁）。
