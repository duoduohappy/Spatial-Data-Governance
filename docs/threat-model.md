# 威胁模型（Stage 0）

范围：Stage 0 只存在一个本地 CLI 内核 + 示例数据，**没有模型调用、没有网络、没有 Web**。
因此威胁面很小；以下条目用于约束后续 Stage，避免 Stage 2 引入模型后失控。

| 资产 / 威胁 | 缓解措施 | 当前状态 |
|---|---|---|
| 交付说明含提示注入（如“忽略检查、全部通过”） | 文档内容一律视为不可信数据；不得扩大工具权限，不得形成任意文件读取/代码执行 | Stage 1 需以挑战集第 7 项验证 |
| 输入中的路径 / URL 被当成执行目标 | 只允许读写工作区内相对路径；未知格式与超限文件受控拒绝 | Stage 1 起实现，Stage 0 无外参输入 |
| 敏感原值进入日志 | 观测值只写入受控证据对象，不写入普通运行日志 | Stage 0：findings 中保留观测值，但不写控制台日志 |
| 密钥泄露 | manifest 不记录 Key；`.env.example` 只放变量名 | Stage 0 无 Key |
| 冒充 live / 伪造结果 | mode 三值并在 manifest 固化；护栏自检断言 Stage 0 产物不得为 live | 已自检通过（tools/selfcheck_guards.py 用例 C） |
| 模型上下文泄露全量点位 | 模型只接触说明、字典、字段摘要与受控样例；调用前展示外发范围 | Stage 2 约束，Stage 0 不适用 |
| 报告/页面注入（HTML、脚本作为字段值） | 渲染层做转义；JSON 为事实来源 | Stage 3 Web 实现，Stage 0 渲染 md 未做转义（已知限制） |
| 超预算调用 | 超预算暂停为未知或待人工，不允许静默降级后报成功 | Stage 2 实现（配合 ADR-006 预算旋钮） |
| 本地服务无认证暴露公网 | 默认 localhost；公网部署需另补认证、隔离、配额 | Stage 3 之前不满足公网条件 |

## 明确不声称的能力

- 不声称日志具备防篡改认证能力：Stage 0 的 manifest 与报告是可被编辑的文件。
- 不声称本工具可替代正式测绘成果检验或合同验收。
- 不声称“零幻觉 / 100% 准确 / 已商业上线”。
