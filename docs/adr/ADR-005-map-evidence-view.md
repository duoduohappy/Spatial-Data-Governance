# ADR-005 地图证据视图作为可降级增强层

- 状态：已采纳（Stage 3 实现）
- 背景：本项目的差异化之一是"问题点位可以在地图上直接点开看"。但地图是外部依赖
  （底图服务、网络、浏览器），一旦不可用，整个验收流程不应该跟着停摆。
- 决策：地图/三维可视化只做**证据展示层**，不参与任何判定：
  - 判定链路不调用渲染，不出参数给渲染，也不等待渲染结果；
  - 底图不可用时自动降级为表格 + 范围 + 问题清单的纯文本审查；
  - 无效坐标（缺失/非数值/越界）的条目必须在表格中出现，即使无法落图。
- 理由：把"看得见"和"判得准"解耦，既保留差异化，又不把可靠性押在底图可用性上。
- 后果：需要为地图层定义降级开关与降级日志；展示层不得反向写入 findings。
- 复审条件：Stage 3 实现前复审接口边界。
