# 本地模型运行与验收说明

本机是 Ollama 便携版＋Qwen3 4B Q4_K_M，模型地址 127.0.0.1:11434，工作台 http://127.0.0.1:8766 。无需 API Key，不产生云端 API 调用费；仍有硬件、下载与电力成本。

## 使用

双击 start-local.cmd。已有工作台时直接打开 8766。启动器不读取云端 Key，不关闭已有千问服务，不安装系统服务或修改系统环境变量。本地项目在 work/local-app，独立于原云端 work/app。

模型程序、权重、专用配置和临时文件分别在 work/local-model/ollama、models、profile、tmp。work/ 不进入 Git、源码 ZIP 或 Docker 上下文。换机器先准备 Python 3.13 和锁定依赖，再执行 tools/setup_local_model.py；脚本校验官方 Ollama v0.40.11 ZIP 的固定 SHA-256，下载 qwen3:4b，建立本地别名 geoacceptance-qwen3:4b。

启动器对本机 API 绕过代理环境变量，防止 localhost 请求意外走代理；沙箱拒绝本机连接时直接提示网络权限问题。重启后不要重新粘贴 Key，只需恢复本地服务及运行权限。

## 资源与性能

RTX 2060 6GB、约 16GB 系统内存实测。一次只加载一个模型、一次一个推理，16K 上下文、q8_0 KV、关闭思考输出，闲置约 60 秒卸载。实际 GPU 模型驻留约 3.9GB（不含桌面及其他程序），资源余量较小。

第 4 轮完整生成的首例约 105 秒，其余约 40–45 秒；首例含模型加载，不是稳定吞吐率。工作台另一次生成约 104 秒。小样本不报告 p95。

OLLAMA_NO_CLOUD=1 已在运行日志确认；应用拒绝外部地址、非指定模型、云凭证及非零云价格。端口已有服务时只复用指定本地模型，不更改别人服务设置。

## 模型与证据编译器

候选分句及可引用行被确定性提取。模型选择支持状态、直接条款绑定、字段、条件、参数以及证据位置；JSON Schema 限制输出结构。程序从规则参数复制实际值，生成来源的标准单位与字面量，再核查是否在原文中，绝不偷偷改成基线答案。类型不合规、依据缺失或条款未解决的规则被隔离，对应要求仍为待澄清。

编译器没有批准或判定权。正常草案也必须逐项审核，尤其是条件、字段覆盖和非数值中文政策的解释。候选识别范围及引擎执行范围均有限，不是任意长文理解系统。

## 实测结果与完整记录

- 前两轮 0/12、1/12 完全通过，失败原始输出均保留。
- 第 3 轮在 Codex 重启前完成 11 个样例，状态 INTERRUPTED，最后一例未声称完成。
- 第 4 轮真实调用 12/12 自动检查通过；其中 3 例缺失依据的规则被编译器隔离。不是模型原始输出零错误。
- 新的 8 份/80 条开发标注要求：原始语义正确 74/80，编译后完整映射 75/80，覆盖 80/80，4 条缺失信息要求均保留未知、来源校验问题为零。未达到完整映射的 5 条仍公开列出。
- 工作台真实生成的明确样例无参数修改，经实现者 Codex 开发复核后 clean/defective/corrected 为 PASS/FAIL/PASS。不是用户本人或外部独立审核。
- 用户指定的内置浏览器已实际保存 JSON 和 HTML，并核对字节一致。
